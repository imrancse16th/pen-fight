     .htaccess
     index.html
     manifest.webmanifest
     icon-192.png
     icon-512.png
     assets\
     img\
     sfx\          (sounds and voices)
     api\         (inside: delete config.local.php before zipping - it is for XAMPP only)
     admin\
     update\

   DO NOT zip: game\  server\  app\  docs\  "Pen Fight Game UI Ida Image"\  PenFight-debug.apk

3) CHECK:  http://pen.devimran.my.id/api/index.php?a=ping   ->  {"ok":true,...,"db":true}
   GAME:   http://pen.devimran.my.id/
   ADMIN:  http://pen.devimran.my.id/admin/

After changing the game: in game\ run  npm run web  (rebuilds and refreshes index.html, assets\, img\ here), then zip again.

QUICK WAY: the file deploy/pen-live-upload.zip is already made (game rebuilt, config.local.php left out).
  cPanel -> File Manager -> public_html -> Upload -> pen-live-upload.zip -> Extract (overwrite).
