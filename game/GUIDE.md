# PEN FIGHT — চালানো, অ্যাডমিন ও আপডেটের গাইড

## 1) পিসিতে চালানো (XAMPP)
- XAMPP-এ **Apache** চালু রাখুন।
- গেম: `http://localhost/pen/game/dist/index.html`
- অ্যাডমিন প্যানেল: `http://localhost/pen/admin/` — ইমেইল ও পাসওয়ার্ড দিয়ে ঢুকবেন (প্রথম অ্যাডমিন বানানোর নিয়ম `api/schema.sql`-এর শেষে লেখা আছে)।

## 2) ডায়মন্ড ও অ্যাডমিন
- প্লেয়ারের আইডি গেমের **শপ** ও **সেটিংস** স্ক্রিনে দেখা যায়।
- অ্যাডমিন প্যানেলে আইডি + ডায়মন্ড সংখ্যা দিলে প্লেয়ার পরেরবার গেম খুললে ডায়মন্ড পায়। `ALL` লিখলে সবাইকে।
- শপ এখন **ডামি**: কোনো আসল টাকা কাটে না। বন্ধ করতে `api/lib.php`-এ `DUMMY_STORE_ENABLED = false`।
- শক্তিশালী পেন (রেড স্ট্রাইকার 60, গোল্ড 150, লেজেন্ডারি 400 ডায়মন্ড) কেনার সময় সার্ভার ব্যালান্স যাচাই করে।

## 3) ফোনের অ্যাপ (APK) সার্ভারের সাথে জোড়া
- ফোন ও পিসি **একই Wi-Fi**-তে থাকবে। পিসির IP দেখুন (`ipconfig`), যেমন `192.168.1.177`।
- অ্যাপে **সেটিংস → সার্ভার ঠিকানা → বদলান** → `http://192.168.1.177/pen/api/index.php`
- না হলে Windows Firewall-এ Apache (পোর্ট 80) আসতে দিন।

## 4) আপডেট পাঠানো (নতুন APK ছাড়া)
কোড বদলে পিসিতে এক কমান্ড:
```
cd C:\xampp\htdocs\pen\game
npm run release -- patch "কী কী নতুন"      # 1.0.0 -> 1.0.1
npm run release -- minor "নতুন অ্যারিনা"   # 1.0.0 -> 1.1.0
```
- এটা নিজে বিল্ড করে `C:\xampp\htdocs\pen\update\` ফোল্ডারে `bundle-x.y.z.zip` ও `latest.json` রাখে।
- ফোনে অ্যাপ খুললে "নতুন আপডেট এসেছে" ডায়ালগ আসে → **এখনই আপডেট** চাপলেই ডাউনলোড হয়ে নতুন ভার্সন চালু।
- সেটিংসে **আপডেট খুঁজুন** বাটনও আছে।
- নতুন **APK** শুধু তখনই লাগবে যখন নেটিভ কিছু বদলায় (নতুন প্লাগইন, আইকন, পারমিশন)।
- পরীক্ষার জন্য: `npm run release -- --dry` (কিছু প্রকাশ হয় না)।

## 5) অনলাইন রুম (আলাদা ফোন থেকে একসাথে খেলা, ২–৫ জন)
- পিসিতে `C:\xampp\htdocs\pen\server\start-room-server.bat` ডাবল-ক্লিক করে চালু রাখুন (একটা কালো উইন্ডো খুলবে, খেলার সময় বন্ধ করবেন না)।
- Windows Firewall-এ পোর্ট **8765** (এবং আগের মতো 80) খুলে দিন।
- গেমে: **অনলাইন রুম → রুম তৈরি করুন** → খেলোয়াড় সংখ্যা, সময়, অ্যারিনা, (ঐচ্ছিক) পাসওয়ার্ড → **রুম আইডি** পাবেন (যেমন `K7M2Q`)।
- বন্ধুরা: **অনলাইন রুম → রুমে যোগ দিন** → আইডি (ও পাসওয়ার্ড) → লবিতে ঢোকে। হোস্ট **খেলা শুরু করুন** চাপলে সবার ফোনে খেলা শুরু।
- হোস্টের ফোন পুরো খেলা চালায়, বাকিরা নিজের পালায় ফ্লিক পাঠায়। কেউ বেরিয়ে গেলে তার পেন AI চালায়; হোস্ট বেরোলে রুম বন্ধ।
- ফোনের সার্ভার ঠিকানা (সেটিংসে) আগের মতোই পিসির IP দিলে রুম সার্ভারও একই পিসিতে ধরা হয়।

## 6) ফোনে ফুল স্ক্রিন ও আড়াআড়ি (Landscape)
- **APK:** নিজে থেকেই আড়াআড়ি, স্ট্যাটাস বার/নেভিগেশন বার লুকানো।
- **ফোনের ব্রাউজারে:** প্রথম টাচে নিজে থেকে ফুল-স্ক্রিন (URL বার লুকায়) ও আড়াআড়ি লক হয়। ফোন সোজা (portrait) ধরা থাকলে "ফোন আড়াআড়ি করুন" বার্তা আসে।
- ব্রাউজারের মেনু থেকে **"Add to Home screen"** করলে অ্যাপের মতো ফুল-স্ক্রিনে খোলে।

## 7) APK বানানো
```
cd C:\xampp\htdocs\pen\game
npm run android:sync
cd android
$env:JAVA_HOME='C:\jdk21\jdk-21.0.13+9'; $env:ANDROID_HOME="$env:LOCALAPPDATA\Android\Sdk"
.\gradlew.bat assembleDebug
```
ফলাফল: `android\app\build\outputs\apk\debug\app-debug.apk`

## 8) পিসি হোস্ট (কাছাকাছি খেলা, ইন্টারনেট ছাড়া)
- পিসি নিজেই হটস্পট (Windows → Settings → Mobile hotspot) বা একই ওয়াইফাইতে থাকলে পিসি হোস্ট হতে পারে।
- পিসিতে `server\start-room-server.bat` চালু রাখুন (পোর্ট 8765; Firewall-এ Private network-এ Allow দিন)।
- পিসির ব্রাউজারে গেম খুলে **রুমে খেলুন → কাছাকাছি → রুম তৈরি** করুন। স্ক্রিনে পিসির আইপি (হটস্পট হলে সাধারণত 192.168.137.1) দেখাবে।
- বন্ধুরা ফোনে **কাছাকাছি → রুমে ঢুকুন** চেপে ওই আইপি দেবে।
